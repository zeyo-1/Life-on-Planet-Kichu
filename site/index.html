        称号ランキング

          1匹の一生は、乱数が決める偶然の連続でした。

          でも1万匹分を集めると、生まれた国による差がはっきり見えてきます。たくさん試して、全体の傾向をつかむ。これがシミュレーションです。

          このゲームは HTML・CSS・JavaScript だけでできています。data.js や story.js を書きかえれば、別の世界も作れます。

          このゲームのしくみ

          シミュレーションとは

          現実の世界を、数字とルールだけの「モデル」に単純化して、コンピュータの中で動かしてみることです。何度も試せるので、現実では確かめにくいことも調べられます。

          きちゅうのモデル

          1. 生まれる国と家を、割合に合わせたルーレットで決める
          2. 1年ごとに、病気・災害・出会いなどのできごとが確率でおこる
          3. 1年ごとに「この1年で亡くなる確率」を計算して、乱数と比べる
          4. 7・13・15・18・22・28・35・40・55・70さいで選択。ただし結果は確率で決まることもある
          5. 一生の終わりに、それまでのできごとから称号が決まる

          画面右上の「しくみモード」をオンにすると、毎年の確率と乱数が見えます。

          いちばん大事な部分のプログラム

          const p = deathProbability(life); // この1年で亡くなる確率
const r = life.random();          // 0以上1未満の乱数

if (r < p) {
  // 乱数が確率より小さければ、一生を終える
  life.alive = false;
} else {
  life.age += 1; // 1さい年をとって、次の年へ
}

          すべて授業用に作った架空の数字です。本物の『80億分の1』は、国連や WHO などの実際の統計をもとにしています。

          乱数と人生番号

          コンピュータの乱数は、じつは計算で作られた「疑似乱数」です。同じ番号（シード）から計算を始めると、同じ乱数が同じ順に出てきます。同じ人生番号で、同じ選択をすれば、まったく同じ一生になります。

          ファイルの役割

          data.js
          国・家・種族の数字。ここを変えると世界が変わる
          story.js
          選択・できごと・称号のシナリオ。新しいできごとも足せる
          sim.js
          シミュレーションの計算だけをする部分
          scene.js
          風景とモンスターのイラスト
          game.js
          画面に表示したり、ボタンに反応したりする部分
          index.html・style.css
          画面の骨組みと見た目
