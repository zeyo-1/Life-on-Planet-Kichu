# きちゅう 1億分の1

モンスターの惑星「きちゅう」で、1匹のモンスターとして一生を送る授業用シミュレーションゲームです。
高校「情報Ⅰ」の「モデル化とシミュレーション」の導入として、5分ほどで遊べるように作りました。

**公開ページ：https://zeyo-1.github.io/Life-on-Planet-Kichu/**

- HTML・CSS・JavaScript だけで動きます（ライブラリや外部サービスは使っていません）
- フォントもリポジトリの中に入っているので、学校のネットワークで外部サイトが見られなくても動きます
- PC・Chromebook・iPad・スマートフォンで遊べます

惑星きちゅうとモンスターたち、国々、数字はすべて架空のものです（実在する国の統計ではありません）。

パソコンの「アニメーションを減らす」設定がオンでも、ルーレットや演出はそのまま動きます（ずっと動き続ける背景の飾りだけ止まります）。

---

## 遊びの流れ（およそ5分）

| 場面 | 内容 | 時間の目安 |
|---|---|---|
| 誕生のルーレット | 「生まれる割合」で区切ったルーレットで国と家が決まる。回転中にクリック（タップ）すると止まる。種族（5種類）と名前も決まる | 30秒 |
| 一生 | 1年ずつ自動で進む。空の色が夜明け→昼→夕焼けと変わり、モンスターも成長する。10回の分かれ道がある | 2〜3分 |
| 称号発表と人生カード | 称号の発表（レア度で演出が変わる）、人生カード、人生グラフ、名場面、寿命くらべ | 40秒 |
| 1万匹の計算 | 同じ日に生まれた1万匹を一気に計算し、国ごとの差・寿命の分布・称号ランキングを見る | 1分 |

### 10回の分かれ道

それぞれの分かれ道には6〜12個の選択肢が用意されていて、毎回そのうち4つが乱数で選ばれて表示されます
（その人の特技や性格に合った選択肢など、大事なものはかならず表示されます）。
しくみモードをオンにすると「全部で何個のうち4個が選ばれたか」も見えます。

| 年れい | 内容 | 結果が確率で決まるもの |
|---|---|---|
| 7さい | 好きな遊び → 性格（6種類）が決まる | |
| 13さい | ひみつの特訓 → 特技（6種類）が決まる | プログラミング・ロボット（ネットが使えるか） |
| 15さい | 進学・就職・ひとり旅・弟子入り・留学など | 進学・留学できるか |
| 18さい | 気になるあの子に、どうする？ | 気持ちが伝わるか |
| 22さい | 仕事（18種類。性格と特技で選択肢が変わる。移住も） | 試験・プロ入り・移住など |
| 28さい | 家族・ひとり暮らし・ペットのモフ・シェアハウスなど | |
| 35さい | 人生最大のチャンス（仕事によって中身が変わる） | 成功するか |
| 40さい | 健康診断・運動・食生活など | 近くに病院があるか |
| 55さい | 人生の後半に何をはじめる？ | 旅行・バンド |
| 70さい | 最後にやってみたいこと | 宇宙旅行・巨大カボチャ |

毎年のできごとは約120種類あります（国・種族・性格・特技・仕事・家族によって起きるものが変わります）。
病気や災害のようにくり返し起きるものは、起きるたびに文が変わります。

一生の終わりに、33種類の称号のどれかがもらえます。1万匹の計算結果から「1万匹中◯匹」というレア度も出ます。

生まれた国によっては、最初の分かれ道（7さい）より前に一生を終えることもあります（1万匹のうち約5%）。
そのときは「小さな星」という称号になります。1万匹の計算結果とあわせて、このモデルで起きる一生の1つとして話題にしてください。

### 授業で使える機能

| 機能 | 使い方 |
|---|---|
| しくみモード | 画面右上のスイッチ。毎年の「亡くなる確率」と「引いた乱数」、できごとの確率、選択肢の成功確率が見える |
| しくみを見る | モデルの説明、いちばん大事な部分のプログラム、国のデータ表 |
| 人生番号（シード） | 人生カードの下に出る番号。同じ番号で同じ選択をすれば、同じ一生になる |
| `?seed=12345` | URL の最後につけると、その番号の一生から始まる。クラス全員で同じ一生を体験できる |
| `?peek=1` | URL の最後につけると、最初からしくみモードがオンになる |

例：`https://zeyo-1.github.io/Life-on-Planet-Kichu/?seed=48213&peek=1`

1万匹の計算はいつも同じ番号（2026）から始めるので、クラス全員が同じ結果を見ることになります。
「計算にかかった時間」だけは、使っている端末によって変わります。

## 公開のしくみ（GitHub Actions）

`main` ブランチに push すると、`.github/workflows/deploy.yml` が動きます。

1. `tools/balance.js` で2000匹分を計算して、シミュレーションが壊れていないか確認する
2. `site` フォルダの中身を GitHub Pages に公開する

`data.js` や `story.js` を書きまちがえたときは公開されず、Actions タブに赤い×が出ます。

### 公開せずに試す

`site/index.html` をダブルクリックしてブラウザで開くだけでも遊べます
（このときだけ「約◯行のプログラム」という行数の表示が出ません）。

## ファイル構成

```
├── .github/workflows/deploy.yml   GitHub Actions：テストして GitHub Pages に公開
├── site/                          公開されるのはこのフォルダだけ
│   ├── index.html                 画面の骨組み
│   ├── style.css                  見た目
│   ├── data.js                    国・家・種族の数字（ここを変えると世界が変わる）
│   ├── story.js                   選択・できごと・称号のシナリオ（新しいできごとも足せる）
│   ├── sim.js                     シミュレーションの計算だけをする部分
│   ├── scene.js                   風景とモンスターのイラスト（SVG）
│   ├── game.js                    画面の表示とボタンの動き
│   └── fonts/                     見出し用フォント（Mochiy Pop One、SIL Open Font License）
└── tools/
    ├── balance.js                 各国の平均寿命や称号の出やすさを確かめるスクリプト
    └── make-font.py               フォントを、使う文字だけに小さくするスクリプト
```

## 世界を変えてみる

`site/data.js` の数字を変えると、きちゅうの世界が変わります。生徒に「どの数字を変えると、何が変わるか」を予想させてから試すのもおすすめです。

- `birthShare`：その国で生まれる赤ちゃんの割合
- `schoolRate`：学校に通える確率
- `clinicRate`：近くに病院がある確率
- `mortality.infant`：0さいの1年間に亡くなる確率

`site/story.js` の `events` に1行足すと、新しいできごとがゲームに出てきます。

```js
{ id: "ufo", ages: [10, 80], kind: "great", rate: 0.01, max: 1, text: "UFOに乗せてもらった！", effect: { happy: 10 } },
```

変えたあと、Node.js が入っているパソコンなら次のコマンドで結果を確認できます。

```
node tools/balance.js 10000
```

いまの設定での結果（1万匹）：

| 国 | 生まれる割合 | 平均寿命 | 学校に通えた | 5さいまでに亡くなった |
|---|---|---|---|---|
| ユタカ国 | 8% | 85.2さい | 97% | 0.1% |
| ミドリ共和国 | 22% | 77.0さい | 92% | 2.0% |
| ハテノ諸島 | 10% | 69.1さい | 84% | 2.7% |
| スナオカ連邦 | 28% | 60.9さい | 71% | 5.2% |
| モリノオク王国 | 32% | 55.5さい | 54% | 8.1% |

story.js に新しい漢字を足したときは、`python tools/make-font.py MochiyPopOne-Regular.ttf` でフォントを作り直すと見出しの字がそろいます（作り直さなくても動きます。足した字だけ別の太字の書体になります）。
作り直したら、`site/style.css` と `site/index.html` にある `?v=` の数字を1つ増やしてください。ブラウザに古いフォントが残らなくなります。

## モデルのしくみ（先生向けメモ）

- **誕生**：国は `birthShare`、家は国ごとの `familyOdds` の重みで抽選（乱数1つで決めるルーレット）。結果は回る前に乱数で決まっていて、クリックで変わるのは止まり方だけ（しくみモードで説明が出る）。種族は見た目だけで、有利・不利はない
- **毎年のできごと**：その年におこりうるできごとの確率を 0〜1 の線に並べ、乱数1つでどれか1つ（または何もなし）を決める。`max`（一生の上限回数）と `cooldown`（次に起きるまでの年数）で、同じできごとが続きすぎないようにしている
- **亡くなる確率**：`事故などの確率 + 年れいとともに大きくなる確率（ゴンペルツ型）+ 乳幼児期の確率` に、けんこう の値で倍率をかける
- **選択**：10回。選んでも、進学・移住・告白・チャンスなどの結果は、国や家、それまでのステータスで決まる確率で判定される
- **称号**：`story.js` の `titles` を上から順に調べて、最初に当てはまったもの
- **疑似乱数**：mulberry32。人生番号（シード）から決まった順で乱数が出るので、同じ番号・同じ選択なら同じ一生になる
