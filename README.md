# きちゅう 80億分の1

惑星「きちゅう」に生まれた1人として、その一生をシミュレーションする授業用ゲームです。
高校「情報Ⅰ」の「モデル化とシミュレーション」の導入として、5分ほどで遊べるように作りました。

- HTML・CSS・JavaScript だけで動きます（ライブラリや外部サービスは使っていません）
- 学校のネットワークでも動くように、外部のフォントや CDN も読み込みません
- PC・Chromebook・iPad・スマートフォンで遊べます

人生シミュレーションゲーム『80億分の1』（Jin's Earth）に着想を得た教材です。
惑星きちゅうと国々、数字はすべて架空のものです（実在する国の統計ではありません）。

---

## 遊びの流れ（およそ5分）

| 場面 | 内容 | 時間の目安 |
|---|---|---|
| 誕生のくじ | 0〜1 の線を「生まれる割合」で区切り、乱数で国と家が決まる | 15秒 |
| 人生 | 1年ずつ自動で進む。15・22・28・40さいで選択がある | 1〜2分 |
| 一生のまとめ | 年輪・選んだこと・同じ国の平均寿命との比較 | 30秒 |
| 1万人の計算 | 同じ日に生まれた1万人を一気に計算し、国ごとの差を表とグラフで見る | 1分 |

生まれた国によっては、選択の年れい（15さい）より前に一生を終えることもあります。
それも「このモデルで起きうる人生」の1つとして、1万人の計算結果とあわせて話題にしてください。

### 授業で使える機能

| 機能 | 使い方 |
|---|---|
| しくみモード | 画面右上のスイッチ。毎年の「亡くなる確率」と「引いた乱数」、できごとの確率、選択肢の成功確率が見えるようになる |
| しくみを見る | モデルの説明、いちばん大事な部分のプログラム、国のデータ表 |
| 人生番号（シード） | まとめ画面に表示される5けたの番号。同じ番号で同じ選択をすれば、同じ人生になる |
| `?seed=12345` | URL の最後につけると、その番号の人生から始まる。クラス全員で同じ人生を体験できる |
| `?peek=1` | URL の最後につけると、最初からしくみモードがオンになる |

例：`https://ユーザー名.github.io/リポジトリ名/?seed=48213&peek=1`

1万人の計算はいつも同じ番号（2026）から計算するので、クラス全員が同じ結果を見ることになります。
「計算にかかった時間」だけは、使っている端末によって変わります。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（Public にする。名前は例えば `kichu`）
2. このフォルダの中身をすべてリポジトリに入れる
   - `git` を使う場合は、このフォルダで `git init` → `git add .` → `git commit` → `git push`
   - ブラウザからアップロードする場合、`.github` フォルダは「隠しフォルダ」なので、ドラッグしても入らないことがあります。
     そのときは「Add file → Create new file」で、ファイル名に `.github/workflows/deploy.yml` と入力し、中身を貼り付けてください
3. リポジトリの **Settings → Pages** を開き、**Source** を **GitHub Actions** にする
4. **Actions** タブで「GitHub Pages に公開」が緑色のチェックになるまで待つ（1分ほど）
5. `https://ユーザー名.github.io/リポジトリ名/` で遊べるようになる

以後は、`main` ブランチにファイルを push するたびに自動で公開し直されます。
公開の前に `tools/balance.js` でシミュレーションが動くか確認しているので、
`data.js` を書きまちがえたときは公開されず、Actions タブに赤い×が出ます。

### 公開せずに試す

`site/index.html` をダブルクリックしてブラウザで開くだけでも遊べます
（このときだけ「約○行のプログラム」という行数の表示が出ません）。

## ファイル構成

```
kichu-life/
├── .github/workflows/deploy.yml   GitHub Actions：テストして GitHub Pages に公開
├── site/                          公開されるのはこのフォルダだけ
│   ├── index.html                 画面の骨組み
│   ├── style.css                  見た目
│   ├── data.js                    国・家・できごとの確率（ここを変えると世界が変わる）
│   ├── sim.js                     シミュレーションの計算だけをする部分
│   └── game.js                    画面の表示とボタンの動き
└── tools/balance.js               各国の平均寿命などを確かめるスクリプト
```

## 世界を変えてみる

`site/data.js` の数字を変えると、きちゅうの世界が変わります。生徒に「どの数字を変えると、何が変わるか」を予想させてから試すのもおすすめです。

- `birthShare`：その国で生まれる赤ちゃんの割合
- `schoolRate`：小学校に通える確率
- `clinicRate`：近くに病院がある確率
- `mortality.infant`：0さいの1年間に亡くなる確率

変えたあと、Node.js が入っているパソコンなら次のコマンドで各国の平均寿命を確認できます。

```
node tools/balance.js 10000
```

いまの設定での結果（1万人）：

| 国 | 生まれる割合 | 平均寿命 | 小学校に通えた | 5さいまでに亡くなった |
|---|---|---|---|---|
| ユタカ国 | 8% | 84.6さい | 97% | 0.2% |
| ミドリ共和国 | 22% | 77.1さい | 92% | 1.1% |
| ハテノ諸島 | 10% | 70.7さい | 86% | 2.9% |
| スナオカ連邦 | 28% | 61.6さい | 71% | 5.7% |
| モリノオク王国 | 32% | 55.3さい | 54% | 8.7% |

## モデルのしくみ（先生向けメモ）

- **誕生**：国は `birthShare`、家は国ごとの `familyOdds` の重みで抽選（乱数1つで決める「区間くじ」）
- **毎年のできごと**：その年におこりうるできごとの確率を 0〜1 の線に並べ、乱数1つでどれか1つ（または何もなし）を決める
- **亡くなる確率**：`事故などの確率 + 年れいとともに大きくなる確率（ゴンペルツ型）+ 乳幼児期の確率` に、けんこう の値で倍率をかける
- **選択**：15さい（進学か就職か）、22さい（働き方・移住）、28さい（家族）、40さい（健康診断）。選んでも、進学・移住・健康診断などの結果は国や家によって決まる確率で判定される
- **疑似乱数**：mulberry32。人生番号（シード）から決まった順で乱数が出るので、同じ番号・同じ選択なら同じ人生になる
